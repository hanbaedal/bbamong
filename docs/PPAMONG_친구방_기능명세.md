# 친구·동호회 예측방 — 기능 정리

> 상태: **확정 / 구현 진행**  
> 기준일: 2026-08

---

## 1. 한 줄 정의

공개 실황 예측은 유지하고, 홈에 **초대 전용 친목방**을 추가한다.  
같은 타석 예측 + **방 멤버 순위**.  
**관리자 비개입·면책**, 방장 종료 시 **친목 데이터 삭제**, **면책·개설 메타만 단기 보관**.

---

## 2. 확정 사항 요약

| 항목 | 확정 |
|------|------|
| 공개 예측 버튼 | 유지 |
| 친목방 버튼 | 예측 버튼 **아래** |
| 빠몽이 위치 | 홈 왼쪽에서 **약간 위** |
| 게스트 | **개설·입장 불가** |
| 입장 | **카카오/웹 초대 링크만** |
| 정원 | **최소 2 · 기본 20 · 상한 50**(프로그램 고정, 방장 설정) |
| 예측 | 공개와 **같은 실황** |
| 방 순위 | 당일(KST) 단순 집계, 공식 성적 아님 |
| 개설 | **면책 동의 필수** |
| 방장 종료 | 방·멤버·초대·순위 **삭제·복구 없음** |
| 감사 메타 | 방장 ID·개설/종료·면책 동의 시각만 **6개월** 보관 후 파기 |
| 팀·나이·지역 | **표시 태그**만 |

---

## 3. 경로

- A: 「실시간 예측게임」 → `/prediction`  
- B: 「친구·동호회 방」 → `/home/rooms`  
- C: 「딜레이 예측게임」 — 준비 중  

- 초대: `/rooms/join/:token`

---

## 4. 면책 (개설 필수 체크)

관리자 비개입·비중재·비복구, 종료 시 데이터 삭제, 순위는 참고용, 예측 정산은 공개 규칙, 약관 위반 시만 이용 제한.

---
