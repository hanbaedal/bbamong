# 친구·동호회 예측방 — 기능 정리 (구현 전)

> 상태: **초안 / 미구현**  
> 목적: 구현 전에 범위·용어·화면·규칙을 고정한다.  
> 기준일: 2026-08

---

## 1. 한 줄 정의

**공개 실황 예측은 그대로 두고**, 홈에 **초대 전용 「친구·동호회 방」**을 추가한다.  
같은 타석 예측을 함께 하며, **방 멤버끼리만** 순위·소속감을 나눈다.

**전제:** 친목방은 회원 간 공간이며, **관리자·운영자는 개설·운영·중재·복구 책임이 없다.**  
방 개설 시 **면책 동의(필수 체크)** 없이는 개설할 수 없다.

---

## 2. 두 가지 입장 경로 (병행)

| 경로 | 홈 UI | 대상 | 역할 |
|------|--------|------|------|
| **A. 공개 예측** | 기존 「예측게임 하러가기」(+ 빠몽이) | 모든 로그인 회원 | 지금과 동일 — 오늘 실황 타석 예측 |
| **B. 친구·동호회 방** | **신규 버튼** (예측 버튼 **아래**) | 초대받은 **정회원**만 | 같은 예측 + **방 단위 순위/멤버** |

- A와 B는 **대체 관계가 아님**. A는 유지, B는 추가.
- 빠몽이 캐릭터는 홈 왼쪽에서 **지금보다 약간 위**로 배치해, 아래 버튼 공간을 확보한다.
- **게스트**는 방 **개설·입장 모두 불가**.

---

## 3. MVP에 넣는 것 / 넣지 않는 것

### 3.1 MVP에 포함

1. 홈: 캐릭터 상향 + 「친구·동호회 방」 버튼  
2. 방 목록 (내가 만든 방 / 내가 들어간 방)  
3. 방 만들기 (방장) — **면책 동의 필수**  
4. **카카오톡 초대 링크** (초대받은 정회원만 입장)  
5. 방 안에서 **공개와 같은 오늘 경기·타석 예측** 참여  
6. **방 멤버만 보이는 순위** (당일 단순 집계, 공식 기록 아님)  
7. 방장: 멤버 내보내기, **방 종료(취소) 시 방 관련 데이터 삭제**

### 3.2 MVP에서 제외 (이후 검토)

| 항목 | 이유 |
|------|------|
| 제목만 보고 **누구나 검색 입장** | 어뷰징·분쟁 위험 → 2단계 |
| 나이·지역 **강제 인증 입장** | 인증·허위 입력 문제 |
| 방마다 **별도 예측 풀·별도 정산** | 운영·실황 연동 복잡도 큼 |
| 방 전용 채팅 | 일정·검수 부담 (원하면 Phase 2) |
| 방 참가비 / 시즌 리그 | 정책·정산 별도 설계 필요 |
| 방 종료 후 순위·멤버 **장기 보관** | 친목 목적·면책·단순 운영 |

## 4. 입장 방식 결정 (비교 결과)

| 방식 | MVP | 설명 |
|------|-----|------|
| **초대 전용 (카카오 링크)** | ✅ 채택 | 방장이 공유한 링크(+토큰)로만 입장 |
| 제목 공개 검색 입장 | ❌ 보류 | Phase 2에서 비밀번호·승인제와 함께 검토 |
| 응원팀·나이·지역 **강제 필터** | ❌ 보류 | MVP에서는 **태그(표시용)** 만 |

**원칙:** 입장의 문은 **초대** 하나. 태그는 “이런 방입니다” 안내일 뿐, 입장을 막지 않는다.

## 5. 방 정보 구조

### 5.1 필수

| 필드 | 설명 |
|------|------|
| 방 이름 | 목록·초대 미리보기에 노출 |
| 방장 | 개설자 (정회원) |
| 초대 토큰 / 링크 | 카카오 공유용, 추측 어려운 값 |
| 상태 | `open` / (종료 시 **삭제**) |
| 면책 동의 | 개설 시 `agreedAt` 등 기록 (동의 없이는 생성 API 거부) |
| 정원 | 방장 설정, **최소 2 · 기본 20 · 프로그램 상한 50** |

### 5.2 선택 (소개·태그)

| 필드 | 설명 | 강제 여부 |
|------|------|-----------|
| 한 줄 목적/소개 | “동호회 정기 모임”, “LG 같이 보기” 등 | 표시만 |
| 응원 팀 | 단일 또는 없음 | 표시만 |
| 나이대 | 예: 20대 / 30대 / 무관 | 표시만 |
| 주거·활동 지역 | 예: 서울 / 부산 / 온라인 | 표시만 |

### 5.3 구조 요약

```
방 = 공간(이름·방장·초대·정원)
   + 면책 동의(개설 필수)
   + 소개(목적 한 줄)
   + 태그(팀·나이·지역) ← 안내용, 입장 조건 아님
   + 활동(같은 실황 예측 + 방 순위)
```

## 6. 면책·관리자 비개입 (개설 시 필수)

### 6.1 원칙

- 친목방은 **회원(방장·멤버) 책임**으로 운영한다.  
- **관리자·슈퍼바이저·경기 운영자는 방의 주최·보증·중재·복구를 하지 않는다.**  
- 일상적인 “강퇴 억울함”, “초대 실수”, “순위 다툼”, “방 삭제 복구” 요청에 **응하지 않는 것**을 전제로 한다.  
- 위법·서비스 약관 위반이 명백한 경우에만 계정·이용 제한 등 **서비스 차원 조치**를 할 수 있다 (방 운영 대행은 아님).

### 6.2 방 개설 화면 UX

1. 이름·소개·태그·정원 입력  
2. **면책 사항 전문(또는 요약+전문 보기)** 표시  
3. 체크박스: **「위 면책·이용 조건에 동의합니다」** — **미체크 시 「방 만들기」 비활성**  
4. 동의 시각·계정 ID를 서버에 저장한 뒤에만 방 생성  

초대 랜딩·방 허브에도 **짧은 면책 안내**를 노출한다 (개설 시 동의의 보조).

### 6.3 면책 문구에 넣을 요지 (약관·UI 공통)

구현·약관 반영 시 아래 취지를 포함한다. (법무 검토 권장)

1. 본 방은 회원 간 친목·자발적 모임이며, **서비스 제공자(관리자)는 개설·운영·초대·강퇴·종료에 관여하지 않는다.**  
2. 방 안 **분쟁·갈등·초대 오남용**은 당사자 책임이다.  
3. 방장이 **방을 종료(취소)하면** 방·멤버 목록·초대 링크·방 순위 등 **방 관련 데이터는 삭제되며 복구되지 않는다.**  
4. 방 순위·태그·소개는 **참고용**이며 공식 기록·보상·보증이 아니다.  
5. 타석 예측·포인트 정산은 **공개 예측과 동일한 서비스 규칙**을 따르며, 방 소속과 무관하다.  
6. 법령·이용약관 위반 시 서비스는 이용 제한 등 조치를 할 수 있다.

### 6.4 방 종료(취소)와 기록

| 상황 | 처리 |
|------|------|
| 방 진행 중 | 멤버·당일 방 순위만 유지 |
| 방장 **종료/취소** | 방·멤버·초대·방 순위 **삭제 (복구 없음)** |
| 멤버 나가기 | 해당 멤버만 제외 |
| 공개 예측 포인트·배팅 이력 | **회원 계정에 그대로 유지** (방과 무관) |

## 7. 예측·정산 모델 (MVP)

**채택: “같은 실황, 방 단위 소속·순위만”**

- 타석 예측·포인트 차감·배당 정산은 **기존 공개 예측과 동일**.  
- **방 순위** = 방 멤버만 모아 **당일(KST)** 적중 수·순이익 등 단순 집계 (공식 기록 아님).  
- 방마다 따로 베팅 풀을 만들지 **않음**.

## 8. 사용자 흐름

### 8.1 방장

1. 홈 → 「친구·동호회 방」  
2. 「방 만들기」 → 이름·소개·태그·정원 → **면책 동의 체크** → 생성  
3. 「카카오로 초대」 → 공유 문구 + 웹 링크  
4. 방 안에서 공개와 같이 예측 참여  
5. 필요 시 멤버 강퇴 / **방 종료(데이터 삭제, 확인 문구에 면책 재고지)**  

### 8.2 초대받은 사람 (정회원)

1. 카카오 링크 탭 → (필요 시 로그인)  
2. 짧은 면책 안내 확인 후 입장 (또는 입장과 동시에 고지)  
3. 유효 토큰 + 정원 여유 + 방 존재 → 입장  
4. 예측 참여 · 방 순위 확인  

### 8.3 게스트·비초대

- 게스트: 개설·입장 **불가** (정회원 전환 안내).  
- 유효 토큰 없음: **입장 불가**.

| 예측 | 기존 `/prediction` + **현재 방 배지** |
| 초대 랜딩 | 토큰 검증 · 면책 고지 · 입장/오류 |

## 10. 권한·규칙

| 주체 | 가능 |
|------|------|
| 방장 | 생성(면책 동의 후), 초대, 강퇴, 종료(삭제), 소개/태그 수정 |
| 멤버 | 입장(초대), 퇴장, 예측, 방 순위 조회 |
| 비멤버 | 초대 링크 없이는 불가 |
| 게스트 | **개설·입장 불가** |
| 관리자 | **방 일상 운영·중재·복구 없음** (약관 위반 시 이용 제한만) |

- 1인 동시 소속 방 수 상한 **제안: 5**.  
- 정원: **최소 2 / 기본 20 / 프로그램 최대 50** (방장이 2~50에서 설정).

## 11. 카카오 초대

- 공유 예: `[빠몽이] {방이름} — {한줄소개}` + 링크  
- 링크: `https://ppamong.com/rooms/join/{token}`  
- 토큰: 추측 불가, **방 종료 시 즉시 무효**  
- MVP: **웹 링크 공유** (카카오 앱 전용 SDK는 선택)

## 13. 공개 예측과의 관계 (운영)

- 공개 예측 조건(오늘 경기·실황 ON·예측 열림)은 **그대로**.  
- 친구방은 “사람 모으기·순위”이며 **실황 엔진·관리자 경기 운영을 대체하지 않음**.
