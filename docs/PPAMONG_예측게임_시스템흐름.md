## 1. 한 줄 요약

| 역할 | 핵심 |
|------|------|
| **관리자** | 경기 등록 → API 연결 → 헬스/배팅 모니터링 → 비상 수동 전환 |
| **운영자** | 타석 **예측 시작/중지/결과** (API로 대체 불가) |
| **사용자** | 포인트 선택 배팅 → 고정 배당 정산 → 공수교대·투수교체 전면·보상 광고 (배너 광고 없음) |
| **API-SPORTS** | 일정·시작 전/종료 스코어·상태. **경기 중(ongoing)에는 점수·이닝 표 덮어쓰기 안 함** (수동 모드도 동일). 타석/문자중계 없음 |

## 2. 전체 구조

```text
API-SPORTS (KBO)
    │  2.5초 폴링
    ▼
중앙 백엔드 (Express)
    │  매핑·정산·광고 트리거·헬스
    ├─ MongoDB (Match / Prediction)
    └─ WebSocket /ws/match
         ├─ 관리자 대시보드
         ├─ 운영자 앱
         └─ 사용자 웹/앱
```

## 3. 역할별 흐름

### 관리자
1. 경기 관리 → 1~5경기 수동 등록  
2. **저장하기** → **API-SPORTS 오늘 경기 연결**  
3. 모니터링: Green/Red, 스코어, 배팅 분포  
4. 이상 시 **수동 제어 전환**

### 운영자
1. 배정 경기 입장 + API 스코어보드 확인  
2. 예측 시작 → (유저 배팅) → 예측 중지 → 결과(1루~아웃)  
3. 다음 라운드 / 광고 시작·중지  
4. 경기 최종 종료는 자동 모드에서 API `FT` 등으로 처리

### 사용자
1. 경기 선택 → 금액(50~1000P) → 예측  
2. 적중 시 `금액 × 배당` / 미적중 소멸  
3. 공수교대·투수교체 시 전면·보상 광고(완료 시 500P). **게임 배너 광고 없음**

## 4. 문제점 점검

| 등급 | 문제 | 영향 | 대응 |
|------|------|------|------|
| **높음** | 타석 결과 API 없음 | 완전 무인 불가 | 운영자 수동 + 비상모드 |
| **높음** | API 연결 누락 | 스코어/자동종료 없음 | 등록 모달 2단계 버튼 |
| **높음** | 1~5 ↔ KBO 매핑 순서 오류 | 다른 경기 스코어 표시 | 연결 후 팀명 확인 필수 |
| **중간** | 이닝변경=광고 휴리스틱 | 광고 오발송 | 운영자 중지 / 수동모드 |
| **중간** | 자동 종료 ≠ 미정산 라운드 | pending 잔존 | 종료 전 결과 입력 규약 |
| **중간** | API 지연 | 중계보다 늦은 체감 | **라이브 중 API 점수 덮어쓰기 OFF** + 운영자/관리자 점수 보정(수동 잠금) + 이닝 표시는 운영자 `gameInning` 우선 |
| **낮음** | 키/리그 ID 오류 | 헬스 Red | Secrets 점검 |
