# 빠몽이 예측 게임 — 시스템 구조 · 흐름

> 기준: 다음 스포츠 + 네이버 실황 · 타석 상태머신 (2026-08)  
> 관리자 시스템 매뉴얼 DOCX와 함께 보세요.

---

## 1. 한 줄 요약

| 역할 | 핵심 |
|------|------|
| **관리자** | 경기 등록 → **실황 ON** → 헬스/배팅 모니터링 → 수동 스코어 전환 |
| **운영자** | **하이브리드**(토글 없음). 예외 시 예측 시작/중지/결과·투수교체·공수교대 |
| **사용자** | 포인트 선택 배팅 → 고정 배당 정산 → 공수교대·투수교체 전면 광고 (배너 없음) |
| **실황** | 다음 스포츠(스코어·이닝·일정) + 네이버(문자중계·주자). API-SPORTS 불필요 |

## 2. 전체 구조

```text
다음 스포츠 / 네이버 릴레이
    │  폴링
    ▼
중앙 백엔드 (Express)
    │  liveAutoOperator · 정산 · 광고 트리거
    ├─ MongoDB (Match / Prediction)
    └─ WebSocket /ws/match
         ├─ 관리자 대시보드
         ├─ 운영자 앱
         └─ 사용자 웹/앱
```

## 3. 역할별 흐름

### 관리자
1. 경기 관리 → 오늘 경기 등록·저장  
2. 운영자 리스트에서 **실황 ON** (기본 1경기)  
3. 모니터링: 스코어, 배팅 분포  
4. 이상 시 스코어 **수동** 보정 (`controlMode=manual`)

### 운영자
1. 배정 경기 입장. 실황이 타석을 돌리고, 버튼을 먼저 누르면 우선(토글 없음).  
2. 자동: 예측 열기 → 닫기 → 결과(아웃/홈런/1루 등) → 다음타자/공수  
3. 수동 루프(예외): 예측 시작 → 중지 → 결과 → 다음타자  
4. **광고**는 투수교체·공수교대 시 시작, **예측 시작**으로 중지  
5. 경기 종료 → 10초 「경기종료」 후 로그아웃

### 사용자
1. 경기 선택 → 금액 → 예측  
2. 화면: 경기전(쿠어스) → 대기(시네마틱) → 선택(3D) → 결과대기(시네마틱) → 큰 글씨 → 적중 시 주루(실사, 홈런은 1·2·3루 후 홈)  
3. 적중 시 `금액 × 배당` / 미적중 소멸  
4. 공수교대·투수교체 시 리워드 광고(약 50초) — 운영자 중지 또는 시간 종료 시 500P. 5초 후 X·예측시작 중지 = 보상 없음. **배너 광고 없음**

## 4. 타석 상태머신 (요약)

`대기 → 예측열림 → 예측닫힘 → 결과확정 → 다음/공수교대`

- 가드: 타자·투수명 안정화, 결과 전 다음타자/공수/광고/투수교체 제한  
- 자동 확정: 아웃↑, 홈런, 1루(안타·포볼·데드볼 + 타자 교체)  
- 하이브리드: 실황이 타석을 진행하고, 운영자 버튼이 먼저면 우선 (토글 없음)  
- 「예측 시작」은 `predictionEnabled`만 — `matchStatus`는 실황 근거
- 예측 열림 기본 **8초** 후 자동 중지
