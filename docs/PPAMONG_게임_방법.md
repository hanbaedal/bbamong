# PPAMONG 야구 예측 게임 — 방법 요약

## 게임이란?

실시간 야구 경기를 보면서 **「다음 타석 결과」**를 맞추는 예측 게임입니다.  
맞추면 **선택금액 × 고정배당** 포인트를 얻고, 틀리면 베팅분은 소멸합니다.

---

## 참여 방법 (회원)

1. **로그인** (`/login`) — 일반·소셜·게스트 로그인 가능
2. **경기 참여** (`/prediction`) — 홈의 빠몽이 / 「예측게임 하러가기」
3. **오늘 경기 선택** (필요 시 「오늘의 경기」 모달)
4. 예측이 열리면 **아웃·1루·2루·3루·홈런** 중 하나 선택
5. 배팅 포인트 확인 후 즉시 차감
6. 결과 확정 후 적중/미적중 연출 · 다음 타석 대기

---

## 예측 선택지 (5가지)

| 선택 | 의미 |
|------|------|
| **아웃** | 아웃 등 |
| **1루** | 1루타·포볼·데드볼 등 1루 진루 |
| **2루** | 2루타 |
| **3루** | 3루타 |
| **홈런** | 홈런 |

고정 배당·배팅 금액은 앱 「사용설명서」·`shared/predictionOdds.ts` 기준입니다.

---

## 한 라운드 흐름

```
실황 자동(또는 운영자): 예측 열림
    ↓
회원: 5가지 중 하나 선택 + 포인트 베팅
    ↓
실황 자동 확정(또는 운영자 결과 입력) → 정산 연출
    ↓
다음 타석 반복 (경기 종료까지)
```

### 규칙 요약

- **라운드당 1번** 예측 (결과 확정 전까지 선택만 변경 가능)
- 예측은 **예측이 열린 구간**에만 가능
- 경기 **취소·종료** 후에는 예측 불가
- 투수교체 등으로 예측이 취소되면 **환불**될 수 있음

## 포인트

| 항목 | 내용 |
|------|------|
| **베팅** | 타석: 50~1000P 선택 / 사이드(우승팀·점수): 별도 금액 |
| **승리** | 선택금액 × 고정배당 |
| **패배** | 배팅분 소멸 |
| **광고** | 공수교대·투수교체 전면 광고 — 운영자 중지까지 시청 시 500P (조기 종료·예측시작 중지 시 보상 없음). **게임 배너 광고 없음** |
| **적립** | 출석, 회원가입 보너스 등 |

---

## 실시간 연동

- **WebSocket**으로 예측 시작·종료·결과·광고를 실시간 수신
- KBO 스코어·이닝은 **다음 스포츠**, 문자중계는 **네이버** (관리자 「실황 ON」 경기)

| **관리자** | 경기·회원·실황 ON·수익·몰 등 전체 운영 |

## 운영자 진행 순서 (요약)

1. 담당 경기 입장 · **실황 자동 ON** 확인
2. 자동이 타석을 돌리면 감시 / 애매하면 「실황 추정」 확인·수동 결과
3. 투수교체·공수교대 시 광고 · **예측 시작**으로 광고 중지
4. 경기 종료 → 「경기종료」 연출 후 로그아웃
