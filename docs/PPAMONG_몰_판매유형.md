# PPAMONG 몰 — 판매 유형 (재고판매 / 주문후조달)

> 확정: 2026년 7월

## 개요

상품마다 **판매 유형**을 지정합니다. 한 몰에서 재고 판매와 주문 후 조달을 함께 운영합니다.

| 유형 | 코드 | 설명 |
|------|------|------|
| **재고판매** | `stock` | 창고 재고 기준. 품절 시 「판매완료」. 주문 접수 시 재고 검사·차감 |
| **주문후조달** | `procure` | 고객에게 재고 미표시. 주문 후 매입·입고·발송 (구매·재고·주문 관리 연동) |

## 재고판매 (`stock`)

### 고객 화면
- 옵션 선택 시 **재고 N개** 표시 (재고가 설정된 경우)
- 재고 0 → **「판매완료」** (빨간 강조), 구매·장바구니 불가

### 주문 API
1. `validateOrderStock` — 수량 부족 시 **400 거절**
2. 주문 저장 성공 시 `decrementStock` — **재고 차감**

### 관리자
- 단일 재고 (`stockQuantity`) 또는 옵션별 재고 (`variants[]`)
- `-1` = 재고 제한 없음

## 주문후조달 (`procure`)

### 고객 화면
- **재고 숫자 숨김**
- `procureNotice` 안내 문구 표시 (기본: 주문 후 7~14일 발송 안내)
- 재고와 무관하게 주문 접수 가능 (가격만 설정되어 있으면)

### 주문 API
- 재고 검사 **생략**
- 재고 **차감 없음** → 이후 **구매관리(발주) → 재고 입고 → 주문 발송**에서 처리

### 관리자
- 판매 유형 = 주문후조달
- 조달 안내 문구 편집

## 4모듈과의 연결 (향후)

| 모듈 | 재고판매 | 주문후조달 |
|------|----------|------------|
| 구매관리 | 리오더·보충 발주 | **고객 주문 → 발주** |
| 재고관리 | 입고·출고·로케이션 | 입고 후 출고 |
| 주문관리 | 접수→준비→택배 | 동일 |
| 판매관리 | 주문 기준 집계 | 동일 |

## DB 필드 (GoodsProduct)

- `fulfillmentType`: `"stock"` | `"procure"` (기본 `stock`)
- `procureNotice`: string (주문후조달 안내)
