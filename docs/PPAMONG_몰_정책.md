# ppamong 쇼핑몰 정책

> 확정일: 2026년 7월

## URL

| 항목 | 값 |
|------|-----|
| **운영 URL (1차)** | `https://ppamong.com/shop` |
| **향후 서브도메인** | `https://shop.ppamong.com` (DNS·Replit 연결 후 동일 MallApp) |

## 정회원 정의

- **정회원:** 사용자 앱에서 가입한 일반·소셜 회원 (`provider !== "guest"`)
- **게스트:** 앱 게스트 로그인 — 몰 **둘러보기·장바구니 담기** 가능, **주문 불가**
- **비로그인:** 동일 (주문 불가)
- 회원가입은 **사용자 앱 전용** — 쇼핑몰 웹에 가입 폼 없음

## 결제

- **1차:** 현금 주문 접수 (배송지 입력 → 관리자 확인)
- **포인트:** 게임 포인트로 **직접 결제하지 않음** (할인·적립은 2차 검토)
- PG 연동은 2차

## 역할

| 역할 | 접근 |
|------|------|
| 사용자 앱 | 게임 + 회원가입 + 쇼핑몰 링크 |
| 쇼핑몰 웹 | 상품 열람·장바구니·정회원 주문 |
| 관리자 웹 | `슈퍼어드민`·`일반어드민`만 — 상품·주문 관리 |
| 매니저 앱 | `/manager`만 (관리자 웹 불가) |

## 삭제·대체

- **삭제:** 빠몽이 보물창고 (`/home?shop=1`, 공개 소개형 홈)
- **대체:** 굿웨어몰형 스포츠 쇼핑몰 (`/shop`)
